# 4주 계획: DB 인덱스 설계와 쿼리 최적화

- **방식**: 평일 중 하루, 2~3시간
- **원칙**: 매 실험마다 **가설 → 전 측정 → 인덱스 적용 → 후 측정 → 결론**을 실험 폴더 README 에 기록
- **산출물**: `results/` 의 측정 파일 + 실험 README 기록 + 4주차 「내가 측정한 숫자로 쓴 면접 답변」
- 주차마다 멘토링 때 보여 드릴 것: 그 주 `make compare` 결과표와 "예상과 달랐던 점" 한 가지
